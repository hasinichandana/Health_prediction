# 🧠 Health AI System

An AI-powered web application that predicts health risks and provides intelligent medical insights.

---

## 🚀 Features

- 🔬 Diabetes Prediction (Machine Learning)
- ❤️ Heart Disease Prediction
- 📊 Risk Analysis Dashboard (Chart.js)
- 📈 Trend Graphs (Diabetes vs Heart)
- 📄 PDF Report Generation (ReportLab)
- 🤖 AI Chat Assistant (OpenRouter API)
- 🔐 User Authentication (Login/Register)
- 🧑‍⚕️ Admin Panel

---

## 🛠 Tech Stack

- Python (Flask)
- Machine Learning (Scikit-learn)
- SQLite Database
- HTML, CSS, Bootstrap
- Chart.js
- ReportLab (PDF)
- OpenRouter AI API
